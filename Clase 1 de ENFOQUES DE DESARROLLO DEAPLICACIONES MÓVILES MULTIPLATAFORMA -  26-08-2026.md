Hacer software es un proceso, es mas que programar. UN software es un producto que soluciona un problema de algun cliente, sea empresa o persona física.
El software es un conocimiento capturado acerca de un área de aplicación.  El software no es solo código ejecutable, sino que también la documentación, diseño, etc. El mantenimiento por ejemplo es  la acción, por ende no es parte del software. Lo que sería parte del software es la documentación, codificación, y todo lo que haga referido a ese mantenimiento, pero el mantenimiento en sí es la acción. -> Definición mas general y buena.

El usuario puede pedir cualquier cosa, el analista o ingeniero ve ese pedido y va a analizar y determinar qué tiene que hacer el software para resolver ese problema. No es lo mismo lo que pide el usuario de lo que hace el sistema. Una cosa son los requerimientos del usuario y otras los requerimiento del sistema (lo que el sistema hace para solucionar el requerimiento del usuario).

La primera versión del software es la especificación de requerimientos.
